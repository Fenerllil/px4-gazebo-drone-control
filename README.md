# PX4 + Gazebo Drone Control

Скрипт автономного управления дроном в симуляции Gazebo.

## 🚀 Быстрый запуск

### 1. Требования
Убедитесь, что у вас установлены:
* Ubuntu 22.04 / 24.04
* Gazebo Sim (Harmonic / Garden)
* Установленный [PX4-Autopilot](https://github.com/PX4/PX4-Autopilot) в домашней директории (`~/PX4-Autopilot`)

### 2. Установка зависимостей

pip install -r requirements.txt
